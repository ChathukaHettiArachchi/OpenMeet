MeetSphere – Video Conferencing Platform
Overview

MeetSphere is a locally developed video conferencing application designed to provide an interactive environment for online meetings.

The project focuses on building an independent conferencing solution with a user-friendly interface, participant management, and real-time communication capabilities.

Objectives
Develop an independent video conferencing application.
Provide an interactive interface for online meetings.
Display participants in an organized tile-based layout.
Include the local user in the participant display.
Provide a popup-based conferencing experience.
Explore technologies for real-time audio and video communication.
Planned Features
Video Conferencing Interface

An interactive interface designed to provide a dedicated environment for online meetings.

Participant Display

Display meeting participants in individual tiles, including the current user.

User Identification

Identify the current user's participant tile with a "(me)" indicator next to their username.

Popup-Based Meeting Experience

Open the conferencing interface inside a large popup/modal window.

Real-Time Communication

Implement real-time audio and video communication between meeting participants.

MeetSphere is intended to provide practical experience in developing a video conferencing platform, including frontend design, participant management, and real-time communication.
